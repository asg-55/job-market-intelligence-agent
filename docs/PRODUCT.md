# Паспорт продукта

## Проблема

Ручной просмотр вакансий занимает время, выдача содержит много нерелевантных позиций, а
адаптация материалов под каждую роль плохо масштабируется.

## Обещание MVP

Дважды в день находить новые вакансии по нескольким поисковым стратегиям, отбрасывать явно
неподходящие, объяснимо ранжировать остальные и присылать лучшие варианты в Telegram.

## Границы v0.1

Входит: официальный HH API, дедупликация, жёсткие фильтры, прозрачный keyword scoring,
SQLite, Telegram и API обратной связи.

Не входит: автоматический отклик, изменение основного резюме на HH, автономное принятие
решений, embeddings, dashboard и обучение на обратной связи.

## Метрики успеха

- precision@10 по пользовательской оценке не ниже 70%;
- не более одного повторного уведомления об одной вакансии;
- не менее 95% запусков мониторинга без необработанной ошибки;
- сокращение ручного просмотра рынка минимум на 30 минут в день;
- сохранение причины каждой оценки для последующего eval-набора.

## Реализовано в v0.2

Генератор сопроводительных писем создаёт аудируемый черновик только из `verified_facts`.
Советник по резюме предлагает фактологически подтверждённые пункты и изменения структуры для
отдельной адаптированной копии и не изменяет выбранный оригинал.
Локальная библиотека хранит несколько именованных базовых резюме для разных направлений,
версионирует изменения и позволяет связать рекомендацию с точной использованной версией.
Именованные профили поиска группируют HH-запросы по трём направлениям и подсказывают,
какое базовое резюме использовать для найденной вакансии.
Локальный пользовательский кабинет заменяет Swagger для ежедневной работы, а Telegram-бот
принимает пожелания и документы PDF/DOCX/TXT через пошаговый диалог.
Рабочая область вакансии показывает объяснение оценки, хранит статус воронки и позволяет
создать рекомендации к выбранному резюме и черновик письма, не покидая кабинет.
Автоматическая отправка и автономный отклик намеренно отсутствуют.
